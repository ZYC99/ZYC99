## 常用工具推荐

### [MathCapture — 公式识别与编辑](https://www.mathcapture.tech/)

这是我经常使用的公式编辑软件，推荐给同样需要频繁处理数学公式的朋友。

- **离线公式识别**：将公式图片转换为 LaTeX，整理数学笔记时很方便。
- **多种编辑方式**：支持可视化编辑和 LaTeX 编辑，可按习惯选择。
- **Word / PowerPoint 集成**：支持插入公式并再次编辑，适合论文、课件和汇报材料。

[访问 MathCapture 官网 →](https://www.mathcapture.tech/)
